数据处理规则

  • 原始 data/daily/*.csv 是审计档案，不会因 V3 迁移而删除或覆盖。
  • 同一天同产品先按市场计算平均；各市场在州或全国平均中等权。
  • 涨跌比较只匹配相同产品、等级、单位、价格层级与市场。
  • 最新调查日期和程序运行时间分别显示；缺失数据不会被估算。
  • GitHub Actions 预约执行不是强保证。备用调度与外部告警需要另行授权配置。
